** Generating paper figures
The 2D landscape figures are produced by ~scripts/all_2d.sh~. This invokes ~rgpycrumbs.cli~ with the current CLI interface (~--dev eon plt-neb~) for each of the three reactions:

| Reaction              | Directory                     | Surface type     | Reference saddle |
|-----------------------+-------------------------------+------------------+------------------|
| Cycloaddition         | ~system_100~                  | ~grad_imq~       | ORCA B3LYP-D3    |
| Grignard              | ~11_grignard~                 | ~grad_imq_ny~    | Birkholz et al.  |
| Bicyclobutane         | ~bicyclobutane_05~            | ~grad_imq_ny~    | mlFSM            |

The Grignard and bicyclobutane datasets exceed 1000 landscape points and use the Nystrom low-rank GP approximation (~grad_imq_ny~). The cycloaddition is small enough for the full GP (~grad_imq~).

#+begin_src bash
pixi s -e cpu
bash scripts/all_2d.sh
#+end_src

Copy the resulting PNGs into the paper repository at ~v1/pccp/imgs/~.

Requires ~rgpycrumbs >= 0.5.0~ and ~chemparseplot >= 1.2.0~.
** Paper schematic figures
The pipeline and dimensional reduction schematics (Figures 1 and 2 in the paper) are defined as TikZ code directly inside ~arxiv.org~ within ~#+begin_export latex~ blocks. They use the RUHI color scheme:
- Teal (~#004D40~) for borders, lines, and text
- Coral (~#FF655D~) for key computational nodes (white text)
- Yellow (~#F1DB4B~) for annotation notes

The required TikZ libraries (~positioning~, ~arrows.meta~, ~fit~, ~backgrounds~, ~calc~, ~shapes.geometric~) and the color definitions (~RuhiTeal~, ~RuhiCoral~, ~RuhiYellow~) are loaded in the org file header. These figures render natively during org-to-LaTeX export with no external image dependencies.

Standalone versions of each figure live in ~v1/pccp/imgs/tikz/~ in the paper repository. To render them as PNGs (300 DPI by default):

#+begin_src bash
cd /path/to/2dvizNEB
pixi run -e texbuild tikz-figs
#+end_src

This calls ~build_tikz.sh~, which compiles each ~.tex~ via tectonic and converts the resulting PDF to PNG with ~pdftoppm~ (poppler). Override the resolution with ~DPI=600 pixi run -e texbuild tikz-figs~.
