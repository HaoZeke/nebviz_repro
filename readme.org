* About
This repository regenerates the figures for
[[https://rgoswami.me/posts/neb-visualizations/][A Field Guide to NEB Path Visualizations]].

The workflow covers:
- PET-MAD model export
- endpoint preparation
- eOn endpoint minimization
- eOn energy-weighted OCI-NEB runs
- readcon v2 checks for generated =.con= trajectories
- rgpycrumbs and chemparseplot figures
- convergence, force, and image-spacing diagnostics

The Atomistic Cookbook version of the eOn/PET-MAD workflow is available at
[[https://atomistic-cookbook.org/examples/eon-pet-neb/eon-pet-neb.html]].

* Usage
Run the complete workflow:

#+begin_src bash
pixi run -e cpu all
#+end_src

Generate only the blog figures from existing NEB results:

#+begin_src bash
pixi run -e cpu figures
#+end_src

Inspect the workflow plan:

#+begin_src bash
pixi run -e cpu dry-run
#+end_src

The blog figures are written under:

#+begin_src text
eonRuns/results/03_figures/blog
#+end_src

The figure workflow also writes:
- =stack.json= with the eOn, readcon, rgpycrumbs, chemparseplot, matplotlib,
  and numpy versions used for generation
- =readcon-v2-summary.csv= from =readcon.read_con= over the generated NEB
  trajectories
